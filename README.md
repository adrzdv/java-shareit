# java-shareit
Сервис для шеринга вещей.
Сервис обеспечивает пользователям рассказывать, какими вещами они готовы поделиться, находить нужную вещь и брать её в аренду на какое-то время. 
Сервис позволяет не только бронировать вещь на определённые даты, но и закрывает к ней доступ на время бронирования от других желающих. На случай, если нужной вещи в сервисе нет, то есть возможность оставлять запросы. По запросу можно добавлять новые вещи для шеринга.
Сервис является многомодульным, состоит из основного сервера и шлюза для приема запросов.

Стек: Java 21, Maven, Docker, Spring Boot, Spring Data, PostgreSQL, Hibernate ORM, Mockito, JUnit
